# 八组图纸的组级任务卡

状态：8组及组级任务卡的结构已获用户认可；本文件中的完整字段、默认值和交互细节仍为设计草案。首版运行范围见 [README](../README.md)，当前只接通四类基础图适配器。

使用结构：**项目共用信息 → 启用的组级任务卡 → 已选图纸的必要参数 → 汇总出图清单**。

直接选图、描述问题与选组可以同时进行。先选一张图时，自动归入相应组；只展开有已选图的组。选组不等于全选组内图纸，也不要求使用者填完8组。

50张图的逐项说明继续作为计算与验收参考；主要交互围绕下面8张组级任务卡展开。

## 通用卡片结构

| 内容 | 使用方式 |
|---|---|
| 本组分析目的（可选） | 允许留空，可用自然语言补充。 |
| 本次选中的图纸及实例 | 支持单张、多张和独立情景实例。 |
| 可共用的场地、数据与分析设置 | 根据实际选择生成检查清单。 |
| 按选图展开的必要参数 | 只针对已选图及其模式展开。 |
| 数据检查与允许的估算 | 根据实际选择生成检查清单。 |
| 表达和交付设置 | 提供可修改的摘要与默认建议。 |
| 汇总清单与验收要求 | 提供可修改的摘要与默认建议。 |

项目位置、范围、坐标和通用样式记录在项目共用信息中，各组引用；不重复索要。覆盖共享设置时，清单明确显示差异。

## 1. 底图分类与标注（11类图）

共用场地底图、分类规则与标注设置，生成选中的基础地图。

### 本组共用设置

| 字段 | 如何填写 | 生效范围 |
|---|---|---|
| 场地、范围与坐标 | 继承项目设置，可明确覆盖 | 所选图纸 |
| 底图来源与版本 | 使用已有资料或选择数据获取方式 | 所选图纸 |
| 共用分类、重点对象与标注密度 | 提供模板，可按图层调整 | 相关图层 |

### 选中相应图纸后才展开

| 图类ID | 需要明确的参数 |
|---|---|
| `roads` | 道路分级体系，是否显示步道和道路名称。 |
| `landuse` | 建筑功能或地块用地；分类体系和未知类的表达。 |
| `gw` | 绿地、水体类别；若显示最近公园，确认距离口径。 |
| `fabric` | 建筑筛选及覆盖率统计范围。 |
| `context`、`location` | 区位尺度层级及背景边界。 |
| `orient` | 真北、图纸北向与场地主轴。 |
| `pedestrian` | 通行人群、开放条件及是否显示过街联系。 |
| `poitype`、`sitemap` | 设施类别和标注数量；最近设施按直线或路网排序。 |
| `combined` | 需要叠加的图层及视觉顺序。 |

### 本组验收

- 底图坐标、范围、北向一致或明确标注差异。
- 分类图例与原始属性一致，未知信息保留。
- 统计表、图面与汇总栏采用同一口径。

示例：勾选道路、建筑肌理、绿地水体，三张共用红线、底图版本和灰绿风格；道路等级单独设置一次。

## 2. 几何处理与空间统计（11类图）

共用原始分析几何和数据版本，按选中指标计算，按需设置统计尺度。

### 本组共用设置

| 字段 | 如何填写 | 生效范围 |
|---|---|---|
| 统计对象与研究边界 | 继承项目边界，选择参与统计的对象 | 所选图纸 |
| 属性来源、完整性与版本 | 复用底图与设施资料 | 所选图纸 |
| 所选指标与单位 | 显示指标解释，保留逐图口径 | 所选图纸 |

### 选中相应图纸后才展开

| 图类ID | 需要明确的参数 |
|---|---|
| `density` | 覆盖率、容积率或相对强度；统计单元。仅后两者要求楼层/楼面资料。 |
| `poiheat` | 设施类别；选择核密度或网格计数，再填写带宽或网格大小。 |
| `urbangrid` | 网格边长、设施类别、计数或密度；可复用兼容的统计网格。 |
| `connectionfield`、`nodes`、`urbanstations` | 节点类别、层级与连线含义；几何近邻与真实线路分开。 |
| `orientrose` | 方向分箱、长度或条数权重、相反方向处理。 |
| `voronoi` | 设施类别及欧氏或路网距离口径。 |
| `typology` | 建筑筛选、排序、同一比例或归一化排列。 |
| `fabricplus` | 概化比例尺、合并距离、院落阈值、简化容差。 |
| `vitality` | 代理指标、权重、时间情景和校准资料；明确相对指数含义。 |

### 本组验收

- 指标定义、分母、单位、尺度与图例可追溯。
- 概化几何不替代原始分析几何。
- 未校准的活力指数不标为实测人流。

示例：同时选建筑覆盖率与设施网格图，共用研究范围；只有用户明确采用同一网格时，两张图才共用网格。

## 3. 路网计算（3类图）

共用可通行网络、出发条件与成本规则，生成到站、可达范围及目的地路线。

### 本组共用设置

| 字段 | 如何填写 | 生效范围 |
|---|---|---|
| 默认起点或入口 | 地图选点或引用已核对入口；允许逐图明确覆盖 | 所选路网任务 |
| 步行人群、速度与通行限制 | 设置步速、台阶、门禁、过街与时间条件 | 真实路网模式 |
| 路网版本与计算范围 | 系统检查连通与外扩取数范围 | 真实路网模式 |

### 选中相应图纸后才展开

| 图类ID | 需要明确的参数 |
|---|---|
| `transit` | 站点类别、站口、最近站选择，以及只展示站点或计算实际到站时间。 |
| `access` | 直线示意或真实路网等时范围；选定时间阈值。 |
| `walkroutes` | 目的地、最近规则、最短距离或最少时间。 |

### 本组验收

- 选中图纸之间的相同起点与通行设置可复用。
- 网络计算范围足够，不被显示范围提前截断。
- 时距由路段成本累计；不可达明确标记。

示例：公共交通到站时间与10分钟可达范围共用北侧入口和步行条件；前者选站口，后者只补时间阈值。

## 4. 高程处理（3类图）

共用一份经核对的地面高程，为等高线、坡向/汇流与剖面表达提供基础。

### 本组共用设置

| 字段 | 如何填写 | 生效范围 |
|---|---|---|
| 高程来源、地面属性与分辨率 | 导入或选取地面高程资料 | 所选图纸 |
| 水平/高程基准、坐标与单位 | 核对米制单位、空值和有效范围 | 所选图纸 |

### 选中相应图纸后才展开

| 图类ID | 需要明确的参数 |
|---|---|
| `contour` | 等高距、高程标注与分层设色。 |
| `aspect` | 坡度单位；仅坡向还是增加汇流；人工设施如何处理。 |
| `wireframe` | 剖面方向、间距、垂直夸张倍数。 |

### 本组验收

- 等高线、坡向与剖面采用同一高程基础。
- 不把建筑/树冠当作地面；空值可识别。
- 图中显示高程单位、分辨率与垂直夸张。

示例：一份地面高程生成等高线和剖面线阵；等高距与剖面间距分别设置。

## 5. 气象与天文统计（5类图）

按已选任务共用位置、合适的数据来源及兼容的统计时段。

### 本组共用设置

| 字段 | 如何填写 | 生效范围 |
|---|---|---|
| 项目位置 | 继承项目位置 | 所选图纸 |
| 气象来源与统计时段 | 选择年份或多年统计；太阳轨迹单独选中时不要求气象序列 | 已选气象统计图 |
| 日期与时区 | 采用可追溯的时间基准 | 相关天文/时间计算 |

### 选中相应图纸后才展开

| 图类ID | 需要明确的参数 |
|---|---|
| `sun` | 节气或具体日期、时区、时间步长。 |
| `climtemp` | 月均日最高/最低温或月极端高低温。 |
| `climprecip` | 月累计降水或月均每日降水。 |
| `climover` | 采用的温度和降水口径，复用已核对统计结果。 |
| `climsolar` | 短波辐射单位，月均每日量或月累计。 |

### 本组验收

- 气象统计的年份、月序和单位一致。
- 气候综合图与单项图共用相同聚合结果。
- 区域气象、太阳轨迹和局部遮挡受晒分别解释。

示例：温度、降水、年度气候共用同一统计期；年度气候直接复用前两项的月统计。

## 6. 三维建模与投影（4类图）

共用建筑轮廓、高度与三维场景，再按不同投影和表达生成图纸。

### 本组共用设置

| 字段 | 如何填写 | 生效范围 |
|---|---|---|
| 建筑与地面模型 | 复用项目几何和已核对高程 | 所选图纸 |
| 高度来源和缺失处理 | 区分测量、已知楼层及明确接受的估算 | 所选图纸 |
| 默认观察方向、投影与比例 | 提供预览，可逐图明确覆盖 | 兼容的图纸 |

### 选中相应图纸后才展开

| 图类ID | 需要明确的参数 |
|---|---|
| `massing` | 高度着色与是否增加瞬时阴影；显示阴影时补日期时刻。 |
| `isogrid` | 共用场地位置或逐栋体量表达、透明度与比例。 |
| `lineaxo` | 隐藏线策略、重点对象与边线表达。 |
| `sunaxo` | 日期季节、受光面定义、主导风来源与统计时段。 |

### 本组验收

- 各图引用同一版本模型，高度与估算标记一致。
- 不同投影不改变原始面积和高度数值。
- 瞬时受光、累计日照与风场不混用。

示例：建筑体量图和线稿轴测共用同一模型，各自选择着色或线稿表达。

## 7. 环境估算、模拟与视线（6类图）

在同一组组织环境相关任务，按噪声、风或照片视线展开独立条件。

### 本组共用设置

| 字段 | 如何填写 | 生效范围 |
|---|---|---|
| 研究对象、范围与情景 | 注明当前研究的环境现象及情景 | 所选图纸 |
| 示意、估算、模拟或真实照片 | 逐图显示可支持的结论 | 所选图纸 |
| 输入来源与允许的估算 | 按当前选项检查资料 | 所选图纸 |

### 选中相应图纸后才展开

| 图类ID | 需要明确的参数 |
|---|---|
| `noise` | 道路相对噪声分区规则与时段。 |
| `soundmap` | 声源类别、推算依据及影响符号含义。 |
| `noisemap` | 道路声源、受声位置、建筑遮挡、简化声学条件。 |
| `wind` | 主导风统计期、来向/流向，明确采用示意流线。 |
| `windsim` | 入流方向、网格、障碍、边界、稳定/收敛条件及量纲。 |
| `viewcones` | 目标、视点、相机朝向、真实照片、遮挡与署名。 |

### 本组验收

- 只检查所选图的条件，不给照片任务索要风场参数。
- 示意与模拟分别标注；缺失数据不伪造观测。
- 数值模拟按相应模型验收，照片按位置、目标和署名核对。

示例：只选真实街景视线展板时，展开视点与照片条件；风和声学设置保持关闭。

## 8. 组合图与设计解读（7类图）

共用已产生的图层、分析结果及表达主题，再组织组合图和设计判断。

### 本组共用设置

| 字段 | 如何填写 | 生效范围 |
|---|---|---|
| 要突出的问题、对象或设计动作 | 可以描述目的，也可直接选择图样 | 所选图纸 |
| 引用的底图、计算结果与方案版本 | 系统列出实际依赖，不自动新增交付图纸 | 所选图纸 |
| 纸张、视窗、图例与统一风格 | 继承项目输出设置并提供布局预览 | 所选图纸 |

### 选中相应图纸后才展开

| 图类ID | 需要明确的参数 |
|---|---|
| `axocallout` | 重点对象与放大窗口。 |
| `insetboard` | 主图和四个小图内容及比例尺。 |
| `zoningplan` | 现状、法定用地或拟建方案，边界/面积与需确认的方案内容。 |
| `radialnet` | 目的地、直线或真实路线、地形与距离圈含义。 |
| `stayplaces` | 停留空间候选、开放性与真实步行连接。 |
| `oppcon` | 事实来源、判断规则、机会/约束内容及设计师批注。 |
| `mappingboard` | 地图或图像来源、尺度层级、构图和可复现随机种子。 |

### 本组验收

- 每个视窗和结论能关联实际结果或人工输入。
- 事实、推断与方案建议分开标识。
- 组合图依赖的辅助计算不增加未选中的交付图。

示例：机会与约束图引用道路、绿水结果，并记录设计师确认的判断；后台复用数据即可，不强制另交一套基础图。

## 一次使用示例

使用者直接选“道路”和“绿水”，并说“研究北侧入口步行便利，最多三张”。

1. 启用“底图分类与标注”卡，显示已选两张，共用位置、底图版本和样式。
2. 推荐“可达性分析”放在候选区；使用者采纳后，再启用“路网计算”卡。
3. 路网卡补充入口、通行条件、步速与时间阈值；其他6组保持收起。
4. 汇总清单显示3张图、各自口径、缺失资料以及需采纳的默认值。

只选道路一张时，仅展开第一组中道路相关条件；不要求填写设施、风场或高程参数。

## 确认与修改

用户确认的是当前组内明确选中的图纸、共享设置和关键差异；没有选中的图、未采纳建议及未来功能不随组级确认自动加入。

某张图的资料不足保留其具体原因，不直接判定整个组不可用。修改共享参数时列出受影响图纸，保留无关设置和确认记录。示意与定量方法的替换需要明确显示，避免静默降级。
