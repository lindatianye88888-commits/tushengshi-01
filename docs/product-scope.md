# 网站其他工具的范围

核对日期：2026-10-25。本文件是范围说明，不代表自建实现或本轮已经逐项运行。

2026-10-27补充：[Lab七项研究的受控观察](lab-diagrams-rea.md)另行记录实际图面、方法自述和运行问题。它们继续作为扩展研究维护，不增加原50类计数，也不代表本项目已经实现。

50项Site Analysis、7项Deep Analysis研究、3D模型和设计工具分别维护。它们不能相加成一个含义不明的“总图数”。设计套图可能复用已有地图，也可能引入新的方案几何和人工决策。

| 工具/产品线 | 使用者需要明确 | 建议生成过程 | 边界 |
|---|---|---|---|
| 3D Site | 范围、地形、建筑高度来源、所需图层与导出格式 | 基础地物→地面与体块→三维预览→格式导出 | 画轴测图不等于已实现原生3DM、OBJ、GLB；分别验证导出器 |
| Site to Design | 红线、项目类型、功能需求、场地约束与设计方向 | 场地解读→场地故事→功能组织→流线→概念→展板 | 官网公开步骤，未在本轮逐项运行；功能面积与方案方向需确认，不能称为规划审批指标 |
| Site Concept | 功能清单、边界、面积、邻接与禁建条件 | 方案分区几何→路径组织→标签→人工调整 | 方案几何与现状数据分开保存 |
| Site Strategy | 已确认问题、设计动作、证据和优先次序 | 事实与判断→策略箭头/轴线/节点→注释 | 可提出候选动作，但设计决策由使用者采纳 |
| Concept / Parametric Lab | 想表达的概念、形态规则、面积/邻接约束 | 参数化几何、约束求解或抽象图形布局 | 结果是概念草案；应保存参数与约束，不能只保存一张图 |
| Bubble diagrams | 空间清单、大小、邻接、分组、必须隔离的关系 | 邻接图→气泡布局→冲突检查→人工拖动 | 图形接近不自动等于可建造的平面 |
| Flow diagrams | 人、车、服务流线，起终点、方向与层级 | 真实路网路线或设计路径→箭头和线型表达 | 分开标注现状可通行路线与拟建流线 |
| Floorplan / AXO | 楼层、墙体、标高、对象、投影与CAD格式 | 结构化平面几何→三维体块/轴测→绘图或CAD导出 | 需要专门几何编辑和导出能力，不能用普通PNG补足 |
| Plan render | 线稿、图层/区域、配色、透明度和保留内容 | 解析区域/遮罩→填色和材质表达→人工校核 | 输入图片与原生矢量的可编辑程度不同 |
| Elevation / Section | 线稿、尺度、材质、环境和人物等配景 | 线稿保留→材质/背景合成→标签和版面 | 效果表达与结构、材料或尺寸真实性分开 |
| Boards / Reports | 选中的成果、纸张、阅读顺序与输出格式 | 读取已完成成果→网格布局→图例/标题→导出 | 拼版和图框变化不另算分析模块 |

来源：[官网工具目录](https://maptonap.com/)、[架构图工具介绍](https://maptonap.com/architecture-diagram-generator/)。

优先完成的范围是catalog/diagrams.json对应的50项图纸需求及其共用计算引擎。其他产品线可以复用数据，但需要另设验收任务，不把它们描述为已经完成的附带功能。
