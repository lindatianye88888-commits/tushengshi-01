# P2A 官网参考核对（REA）

核对日期：2026-10-26。公开目标：[MapToNap App](https://maptonap.com/app?free=1&lang=en)。本记录用于约束自有实现的名称、方法与支持范围，不宣称算法或成果与网站等价。

## 核对方式与边界

使用 REA 的 `capture_browser_scenario` 启动独立、空白存储的隐藏 Chrome，读取公开页面 DOM、可访问性和截图，点击官网明确提供的巴黎免费样例，并关闭样例后的继续购买提示。未使用用户现有浏览器页面；未登录、购买、改变解锁状态或生成付费图。

七类 P2A 图在公开菜单中均标为 PRO 或 MAX，因此本轮没有观察它们对指定场地实际生成的结果。菜单短说明与公开静态缩略图只能证明功能声明或图面示例，不能证明相应后台算法已执行、默认参数、计算准确性或导出能力。

历史研究中的 50 类是本项目固定排期的范围；本次公开页面已显示 **51 analyses**，增加 `Urban Growth`。这是官网当前观察，不自动扩大本项目的 50 类开发范围，也不计为本项目已实现能力。旧研究证据保留原日期。

## 七类对照

以下“官网说明”来自当前公开 DOM 目录元数据；“自有实现”来自本轮 P2A 代码与任务模式，属于独立设计。公开目录下方的付费锁定状态另由可访问性确认。

| ID | 官网名称及短说明（观察） | 自有模式及可支持的对照结论 | 尚未验证 |
|---|---|---|---|
| `context` | City Context；场地在城市中的位置关系 | 来源行政城市面与项目局部道路视窗。满足城市定位表达；全城路网未取数时只画本地范围，不补画联系线 | 官网是否使用真实行政面、城市轮廓、全城路网或多尺度视窗 |
| `location` | Location；场地在国家与区域中的位置 | 当前为**省—市—区定位**，成都案例对应四川—成都—成华；国家尺度尚不支持。不能称已覆盖官网的国家定位模式 | 官网国家边界来源、投影、层级和具体图面 |
| `orient` | Orientation；方位与朝向关系 | 由坐标计算真北；项目主轴需有来源的人工方位。无主轴时明确标记缺失，不从分析圆推断朝向 | 官网方位基准、主轴提取方法与旋转处理 |

## 发现与实施约束

1. **必须保留两处支持范围差异**：Location 目前缺国家尺度；Fabric Generalisation 目前缺街名。可运行登记需带模式，不能用同名目录暗示全部细节完成。
2. Pedestrian Network 目前只能声称通行属性底图，不等同于可达性计算；步道、广场和公共空间的完整性依赖实际数据，不可用未知属性当允许通行。
3. 官网七类的具体图面均未实际生成，本轮没有足够证据要求复制其颜色、布局或宣称视觉一致。现有自有图面是否清晰、统计是否正确，应通过自有真实案例和独立复跑验收。
4. 免费样例中同屏汇总显示 1,956 建筑、39% 覆盖率；单图显示 1,181 建筑、24% 覆盖率。这里只记录可见差异，未核对其统计范围或成因，不据此判断哪个数正确。自有实现必须使汇总和单图引用相同指标来源，或明确范围差异。
5. 本轮未检查网站后端或对代码字符串作执行归因。付费图的计算方法、数据缺失处理、误差和性能仍未知；不以静态文本填补这些未知。
