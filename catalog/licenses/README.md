# Places资料署名与许可文件

Overture设施点的来源许可与建筑、道路不同。逐对象`sources`保留原始来源，图面按本次实际来源署名，任务保存许可文件路径。本目录随含数据成果包一起交付，不将Places统一标为ODbL。

- Apache-2.0、CDLA-Permissive-2.0、CC0-1.0文本取自[SPDX官方许可文本库](https://github.com/spdx/license-list-data/tree/main/text)。
- Foursquare-NOTICE.txt保留[官方Places Notice正文](https://opensource.foursquare.com/places-notice-txt/)，未包括页面导航和CSS。
- 来源对应关系依据[Overture官方署名页](https://docs.overturemaps.org/attribution/)。未知提供方保留“see source license”，不猜许可。

此工作流对资料进行了区域提取、投影转换、属性规范化、明确筛选及可选的同名同类同坐标去重。分析表和图形为进一步派生成果；来源ID、原始属性及筛选审计保留。Foursquare资料已由Overture转换到其schema，本工作流再作上述处理。署名文件不证明资料已现场核实。
