# v0.4 · 第二批七类模式验证记录

本批为城市区位、多级行政定位、真北参考、步行来源属性、图层叠加、肌理概化、路口几何关联实现各自明确的首个模式。原50类排期内累计14类有可运行模式，另36类待开发；扩展模式不因同名图类已登记而自动可用。

## 来源与方法

场地为成都万象城，WGS84中心104.1126387、30.6507515，分析半径5000米、取数5500米，EPSG:32648。版本固定Overture 2026-10-21.0。行政面和连接点为新增真实公开资料；道路重新提取完整连接点、通行限制及其区段属性。规范化后有53467个建筑、12112条道路、13061个连接点、81个行政面；这些是取数区资源数量，不能与5000米分析区对象数混用。

道路及行政面保留来源完整几何，避免线性引用位置失真或把5公里圆圈变成行政边界；统计及显示时再分别裁剪。缺失道路层级记为unknown，不假设地面层。逐对象来源保留，遥感屋顶投影不是测绘实测基底；行政范围也不作为法定边界依据。

多资源图的缓存、分析、冻结输入和完整性检查均覆盖所有依赖哈希。朝向图不需要外部数据，以任务坐标和已提供方位为来源。面积、长度、数量、图层和角度分别记录，不统一解释为覆盖率。

## 遇到的问题及处理

- 完整道路含大量嵌套限制字段，逐个小范围HTTP读取使两个镜像在首轮超时。已保留旧缓存，并为相邻小读取加入1MiB对齐缓存；返回给Parquet的字节范围和游标仍精确，后续真实提取成功。超时或不完整响应仍报错，不当作零对象。
- 旧版道路缓存没有通行与连接点字段，不能用于新两类。已检查缓存实际列；新旧缓存并存时继续查找满足要求的缓存，离线找不到时明确要求重新取数。
- Arrow嵌套结构会带出未使用的null条件字段；已忽略这些空字段，避免把空条件误判为通行限制，附回归算例。
- 成都约52.76%的来源线长通行未知、46.12%需核对条件；明确允许仅约0.73%。这些数是属性资料覆盖状况，不能据此判断真实可步行比例。
- 仅有圆形研究范围，不能推断项目红线朝向。当前输出真北参考，未补造主轴。
- 复查修正了环形道路两端接同一连接点的支路累计，并对重复引用去重，附算例。实际成都输入中无此重复连接点记录，修正后单独重算路口图再次核对结果。
