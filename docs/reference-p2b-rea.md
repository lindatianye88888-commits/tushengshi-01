## 七类可见说明与自有模式

下表对官网短说明作中文转述。拟实现模式来自项目开发任务，是否完成须以本地测试、真实案例和独立复跑的验证记录为准，本文不单独改变可运行数量。

| ID / 官网名称 | 官网公开声明与图面观察 | 自有模式及应明确的差异 |
|---|---|---|
| `poitype` / POI Type Map | 按设施类别区分。圆形底图上有密集、多色点符号，并有少量黑色符号；公开缩略图没有可读的完整图例 | 使用来源 POI 属性分类，保留原始类别及未知类。点色含义由自有图例定义，不能从官网示例点色反推分类规则 |
| `sitemap` / Annotated Map | 真实底图上的最近设施标注。示例有类别字母小圆、设施名称、建筑及水面背景 | 最近设施按项目中心欧氏距离筛选，编号对应名称和距离清单；如只在地图放编号，应登记为**编号索引标注模式**，与官网图内直接标名称有表达差异。直线距离不代表步行路径或时间 |
| `poiheat` / POI Density Heat | 表达设施集聚。示例是连续暖色热力，附几个含 100m 口径的设施数量标签 | 自有高斯核密度带取数缓冲区，公开带宽、权重、单位和裁剪规则。不能照抄示例单位：图面不足以证明官网采用高斯核、其数值是核密度还是邻域计数，也不能证明其边缘修正 |
| `voronoi` / Service Territories | 声明泰森分区和服务空缺。示例可见设施点、不规则多边形，以及局部浅红渐变底 | 自有采用欧氏最近点分区，缓冲区内竞争点参与后裁剪到分析范围。**几何分区不自动构成服务缺口判定**；未配置距离阈值和适用设施类别时，只称最近设施分区。不是沿路网可达范围，不包含容量、等级和出入口约束 |
| `urbangrid` / Urban Data · Grid | 网格内设施数量。示例为深色底上的青色规则格网，深浅不同 | 自有为独立 POI 点数统计，给出网格尺度、边界归属、有效面积与计数。示例无法确认官网是否计数去重、是否作面积归一化；自有格网计数不等同于核密度 |
| `urbanstations` / Urban Data · Nodes | 强调真实设施与交通节点。示例满幅青色点背景中叠加紫色空心圈 | 若只实现真实站点分布和周边设施计数，应登记为该模式；与示例的设施背景和叠加点表达有差异。示例没有可读图例，紫圈的具体站点类别不能凭外观认定。缺少真实站点资料时，不把普通 POI、推导中心或格网热点伪造为地铁站 |
| `nodes` / Node Analysis | 声明空间节点与轴线。示例有建筑轮廓背景、红色具名节点及节点间线条 | 自有为项目中心附近节点分级、来源名称和直线距离联系。**径向联系是自定表达模式**，不能称已实现官网的自动城市主轴、实际交通线路或功能联系。节点类别和分级规则需写入方法 |

五类 PRO 为 `poitype`、`sitemap`、`poiheat`、`voronoi`、`nodes`；`urbangrid`、`urbanstations` 属 MAX。本轮未点击锁定项或触发付费运行。

## 观察、推断和未知

**已经观察**：七类当前名称、公开目录短说明、锁定层级及示例图片地址；七张静态图的点/线/面及文字表现。官方四图免费样例仍属于此前 P2A 的实际运行观察，不延伸为本批七类执行证据。

**可作的有限推断**：官方表达将类别点图、设施注记、连续热力、最近设施分区、规则网格和节点图分别组织；因此自有七类也应具有不同计算合同与图面，不能只替换标题或点色。对具体视觉特征的判断仅限约 300×300 的示例，不据小图中的色彩或连线解释真实数据语义。

**仍然未知**：官网的 POI 数据完整性、重复与闭店处理、类别映射、最近距离口径、核函数/带宽/单位、Voronoi 外部竞争点处理和缺口阈值、网格原点/大小/归一化、站点分组去重、节点优先级、轴线来源、付费导出和任何计算精度。本轮没有从 JS 字符串推断其后台算法已经执行。

## 对本批实施和验收的影响

1. 最近设施、KDE、Voronoi 和站点周边计数都需要明确取数范围及分析范围。有限缓冲区只是边缘处理策略；是否足够需按自有算法和测试验证，不能因官网有类似图就认定正确。稀疏点、同坐标点、边界点和缓冲区外竞争点必须有明确处理。
2. `sitemap` 地图编号与旁表名称可以构成可追溯索引，但应保留“编号索引”模式说明；与直接文字标注的差异不可隐藏。
3. `voronoi` 未实现服务缺口判定时，不使用“已覆盖服务空缺分析”的说明。欧氏最近点不代表真实医疗、教育或公共交通服务能力。
4. `urbanstations` 的真实站点和来源 POI 应各有身份及类别证据。周边设施数不是上下客量、客流、班次、公交线路或换乘可达性；没有相应数据时不得填入这些指标。
5. `nodes` 的关系线应在图例标为几何联系或直线距离。若无设计主轴或实际线路来源，保留未知，不从节点间直线自动命名城市主轴。
6. 若要贴近示例表达，可补齐设施背景、具名注记及建筑底图；这是图面表达选择，不是后台算法等价性的证明。本轮证据不要求复制官网配色或版式。
