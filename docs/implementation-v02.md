# v0.2 通用执行与跨端协议

这一版把成都专用试跑整理为统一入口，保持四个基础绘图适配器的范围。

| 阶段 | 实现入口 | 核对内容 |
|---|---|---|
| 对话转请求 | request.py / request.schema.json | 新增与删除显式区分，推荐保持候选，授权依据可追溯 |
| 位置与范围 | project.py | WGS84中心、局地UTM、显示/分析/取数范围 |
| 数据获取 | providers/overture.py | 固定release、空间过滤、缓存范围、镜像与分块校验 |
| 资料规范化 | ingest.py | 唯一ID、原始属性、实际相交、坐标转换、清理记录与来源署名 |
| 任务编译 | compiler.py / task.py | 按所选图检查依赖，兼容参数继承，覆盖差异与状态分开 |
| 计算与绘图 | analysis.py / render.py | 同一统计结果驱动图面和表格，数据缺项不补成真实零值 |
| 冻结与重绘 | engine.py / repaint.py | 按哈希保存输入，样式修改复用计算，无关成果可复用 |
| 预览与验收 | delivery.py / integrity.py | 实际预览、哈希与合计检查、核对人和意见记录 |
| 成果迁移 | delivery.py bundle | 解压后具有独立的配置、输入、运行证据和执行器 |

公开数据查询以研究范围的外包框筛选后，再核对真实几何相交，避免把跨日期变更线的异地大包围框当作场地对象。覆盖声明采用已核对的保守取数范围，查询外包框另存，避免四角投影造成的边缘误差。

本地业务状态包括 confirmed / ready / needs_review / complete 等，分别表达需求、数据与成果。complete 的含义是本次出图验收已记录，不代表测绘或审批结论。

四类适配器：roads、fabric、landuse、gw。50类完整目录中的其他46类仍保持 not_implemented，不采用替代算法冒充其结果。

后续按依赖分批接入：建筑覆盖率与类型学等空间统计，随后是明确通行限制的真实路网，高程、气象与太阳参数，最后是需要专门验证的模拟及设计解读。
